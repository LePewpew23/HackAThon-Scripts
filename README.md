# HackAThon-Scripts
Script	                  Purpose
baseline.sh	              Capture system information, users, ports, processes and services
backup.sh	                Back up key configurations locally or transfer to blackbox
passwords.sh	            Safely change plinktern or jmoney passwords interactively
ssh-harden.sh	            Back up and inspect SSH configuration before manual hardening
firewall-ubuntu.sh	      Configure UFW for Ubuntu
firewall-fedora.sh	      Configure firewalld for Fedora
persistence-audit.sh	    Look for suspicious accounts, SSH keys, cron jobs and systemd units
service-check.sh	        Test HTTP service availability and expected content
changes-diff.sh	          Compare two baseline reports
lib.sh	                  Shared functions used by the other scripts
